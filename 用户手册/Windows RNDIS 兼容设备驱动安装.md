# Windows RNDIS 兼容设备驱动安装

1. 用type-c线连接产品和电脑，会有硬件插入提示声
2. 按Win+R输入`devmgmt.msc`点确定，弹出设备管理器页面
![[Pasted image 20260807011226.png|585]]
3. 找到其他设备，展开找到名为RNDIS的设备
![[屏幕截图 2026-08-06 015310.png|585]]
4. 右键后，点击更新驱动程序
![[屏幕截图 2026-08-06 015353.png]]
5. 后面逐步跟着图片操作即可
![[屏幕截图 2026-08-06 015628 1.png|518]]

![[屏幕截图 2026-08-06 015652.png|520]]

![[屏幕截图 2026-08-06 015817.png|524]]

![[屏幕截图 2026-08-06 015902.png|526]]

![[屏幕截图 2026-08-06 015935.png]]

![[屏幕截图 2026-08-06 020001.png|535]]

显示安装完成后，按Win+R，输入cmd唤出命令行，输入`ping 192.168.137.2`
显示：![[Pasted image 20260807010413.png|492]]
即配置成功
