# 镜像刷写与删除桌面环境

镜像下载：[Orange Pi Zero2W | Armbian](https://armbian.com/boards/orangepizero2w)
使用balenaetcher将镜像.img文件烧录在TF卡中，开机根据指引进行配置。
配置完后，进入ssh终端，be like:
![[屏幕截图 2026-08-06 232407.png|591]]
输入
```text
armbian config
```
出现伪图形界面，be like:
![[Pasted image 20260806232915.png|523]]
此处会有uninstall xfce选项（当前已卸载所以无）
键盘控制执行等待即可
